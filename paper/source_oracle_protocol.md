# 答案来源约束的离线诊断规格（探索性）

本分析在两轮评阅与多次查看既有结果后提出。冻结计算口径不使它成为确认性实验；不新增训练，不计入八锚点验证的完成数，也不提出新指标或解码方法。

1. 使用两轮目录内已完成的数字答案分支；六字母臂因覆盖不足排除。来源目录及分支名共同标识记录，不把续训副本、共享锚点或上下文当独立重复。
2. 与主概率分析相同，使用 16 个活跃原题键、每键前两个固定测试上下文。保留模型原始正确 Cedar 质量及完整 Cedar 候选质量。
3. 外部给定“正确答案属于 Cedar 候选集合”，分别在全部 48 个已学 Cedar 值、以及同一活跃原题的 16 个 Cedar 值内，计算最高序列概率的命中率。并列最高者按 1/并列数计分；零候选质量不定义条件读数，报告覆盖。规范序列概率包含 EOS。
4. 同时报告逐题归一化后的正确 Cedar 份额。这只是受限集合内的条件读数，不能代替模型原始输出质量或自由生成准确率。对 Cedar 原始集合质量大于 1e-8、1e-4 的子集另报敏感性与覆盖，不把极小剩余质量放大后称作可用知识。
5. 48 值读数的置换在全部 48 个旧值对应键内进行，因为它们都在 Cedar 阶段训练过；16 值读数在同一活跃 16 键内置换。每个键的两个上下文共同使用一个标签置换。每点 2000 次，固定种子由目录、分支名和观测点的 SHA256 导出；报告零分布分位数与探索性尾概率，不作跨比较的确认性显著性宣称。
6. 数字前缀诊断测量“受限 Cedar 最高分答案是否与当前同键 Maple 值共享前两位”。其零分布只在 16 个训练原题的 Maple 赋值之间置换，保留预测、值支持与组机会数；该结果只说明输出的词元结构关联，不解释隐藏表示因果机制。
7. 观测点包括起点、第 64 步、若覆盖则第 640 步、实际终点，以及 PAVA 对齐的验证 logP −1.0/−0.5/−0.3/−0.1；未达目标不外推。原始首次 −1.0 的实测点单列，存在逐题生成时只抽取同样两个测试上下文对照，禁止把插值概率当成插值模型的生成准确率。
8. 重点描述既有种子 211、223、227 的相邻与支持集保持打散，在相同验证目标 −1.0 的配对差，并列出更高目标覆盖。−1.0 是低质量诊断位置，不据此宣称同时解决两个任务。所有其他分支和时间点完整提供，避免只选有利终点。

结果查看后追加的解码口径核对：另列全部 96 个规范答案中的旧值最高分命中率，作为相同序列评分、仅未加来源限制的对照。它也不是原生逐 token 贪心。该补充用于避免把候选约束与序列级 MAP 对逐 token 贪心的差别混为一谈，不改变前述主读数与标签置换规格。早期点的“活跃训练集合”是预定的 Maple 支持，不表示第零步已经训练 Maple。

任务身份已知的持续学习评估是已有问题（van de Ven 与 Tolias，2019，arXiv:1904.07734；Nori 与 Kim，2024，arXiv:2410.20768）。这里给解码器一个额外的候选集合约束，而原提示中本来就有注册表标签，不能把两种设置等同；这种外部约束也不能证明知识未被擦除，或证明模型已自行利用标签。
